# Employee Security Checklist

## Before Clicking
- Was I expecting this message?
- Does the sender make sense?
- Is there unusual urgency?
- Where does the link actually go?
- Is an attachment expected?

## Accounts
- Use unique passwords.
- Enable MFA.
- Never share authentication codes.
- Report suspected compromise immediately.

## Devices
- Install updates.
- Lock your screen.
- Use approved software.
- Avoid unknown removable media.
