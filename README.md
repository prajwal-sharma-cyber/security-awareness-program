# Security Awareness Program

A practical security-awareness programme for a fictional organisation, focusing on phishing, passwords, MFA, reporting and safe information handling.

## Programme Goals
- Reduce human-related security risk.
- Teach employees to recognise suspicious activity.
- Encourage fast reporting.
- Reinforce secure authentication.

## Training Modules
1. Passwords and passphrases
2. MFA
3. Phishing
4. Safe browsing
5. Data handling
6. Remote-work security
7. Incident reporting

## Measurement
Track training completion, suspicious-email reporting, repeat-risk behaviour and time to report.

Avoid collecting unnecessary personal information in training metrics.

## Skills
Security awareness, risk communication, human factors and security governance.
